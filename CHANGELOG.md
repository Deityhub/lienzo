# Changelog

All notable changes to this project are documented in this file. New entries are generated by the Prepare Release workflow from [Conventional Commits](https://www.conventionalcommits.org/), following [Semantic Versioning](https://semver.org/).

## [2.0.0](https://github.com/Deityhub/lienzo/compare/v1.1.0...v2.0.0) (2026-11-07)

### Features

- template gallery with 22 templates, a page for each, and sorting on the documents page
- tool palette that adds on click, and headers that collapse to icons instead of wrapping
- tidier property panel, a phone sheet and rulers with values ([#46](https://github.com/Deityhub/lienzo/pull/46))
- new logo, favicons, app icons and social preview image
- one export dialog and a tidier editor header
- Studio home page ([#43](https://github.com/Deityhub/lienzo/pull/43))
- Fluent 2 colours and a light and dark theme
- copy, cut, paste and duplicate elements, and paste pictures ([#41](https://github.com/Deityhub/lienzo/pull/41))
- move elements and groups between pages ([#40](https://github.com/Deityhub/lienzo/pull/40))
- select, group and resize multiple elements ([#39](https://github.com/Deityhub/lienzo/pull/39))
- save documents automatically while editing
- export PDFs with real text and vector shapes
- import documents from Lienzo-exported PDFs
- add JSON import and export for documents
- add document schema versioning, migrations and IndexedDB tests

### Bug Fixes

- templates open in the editor exactly as designed
- root favicon, uncut favicon icon, and a System option for the theme switch
- scale text with the page on smaller screens

### Refactors

- slim down the canvas page
- move canvas drag and resize into controllers
- split CanvasElement into per-type views and extract shape geometry
- split PropertyPanel into per-element panels
- extract canvas geometry into tested utilities

### Documentation

- rewrite the README, add contributing, security, code of conduct and third-party notices, and fresh screenshots

## 1.0.0 (2025-11-28)

First tracked release.

### Features

- Drag-and-drop document canvas with text, shape and image elements
- Multi-page documents with page boundaries, rulers and snap-to-grid
- Element layering, nested elements and resize handles
- Text properties (font, size, weight, style, color, background color and opacity) and extended shape properties (stroke, fill, opacity, corner radius, rotation)
- Image elements with alt text
- Export to PDF with preview
- Save, list, search, edit and delete documents locally (IndexedDB)
- Touch support for adjusting page boundaries
- Accessibility improvements
- Landing page, documents page and GNU GPLv3 license

### Bug Fixes

- Fixed disappearing and cut-off elements while dragging
- Fixed element coordinates when dropping onto another element
- Fixed PDF export issues
