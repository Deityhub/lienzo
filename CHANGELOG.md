# Changelog

All notable changes to this project are documented in this file. New entries are generated by the Prepare Release workflow from [Conventional Commits](https://www.conventionalcommits.org/), following [Semantic Versioning](https://semver.org/).

## 1.0.0 (2025-11-28)

First tracked release.

### Features

- Drag-and-drop document canvas with text, shape and image elements
- Multi-page documents with page boundaries, rulers and snap-to-grid
- Element layering, nested elements and resize handles
- Text properties (font, size, weight, style, color, background color and opacity) and extended shape properties (stroke, fill, opacity, corner radius, rotation)
- Image elements with alt text
- Export to PDF with preview
- Save, list, search, edit and delete documents locally (IndexedDB)
- Touch support for adjusting page boundaries
- Accessibility improvements
- Landing page, documents page and GNU GPLv3 license

### Bug Fixes

- Fixed disappearing and cut-off elements while dragging
- Fixed element coordinates when dropping onto another element
- Fixed PDF export issues
